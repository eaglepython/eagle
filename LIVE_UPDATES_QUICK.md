# Live Updates: Quick Guide

- The screen currently displays bundled sample insights in five categories.
- While the app is open, its local timestamp and history refresh every two hours; manual refresh is also available.
- It does not fetch live internet, news, market, or job data yet. Treat the cards as examples.
- Closing the browser stops the timer.
- Netlify can separately rebuild the published app after pushes to the connected Git branch. That updates app code, not the sample insights.

See [LIVE_UPDATES_GUIDE.md](LIVE_UPDATES_GUIDE.md) for details and the path to adding a server-side data source.
